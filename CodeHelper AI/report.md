# Итоговый отчёт
## Создание собственного AI-помощника для программиста

### 1. Назначение помощника

В рамках домашнего задания был разработан концепт AI-помощника CodeHelper AI. Его основная задача — помогать программисту выполнять повседневные задачи, экономить время и быстрее находить ошибки в коде.

Помощник предназначен для начинающих и опытных программистов.

### 2. Выбранные функции

В помощнике предусмотрено пять функций:

1. Объяснение программного кода.
2. Анализ ошибок Python.
3. Создание тестов для функций.
4. Создание документации.
5. Поиск возможных проблем в коде.

### 3. Использованная LLM

Для выполнения задания использовался ChatGPT — готовый AI-сервис, который может анализировать программный код, объяснять его и генерировать примеры.

Подключение API и создание собственной языковой модели не выполнялись, так как это не требовалось по условию задания.

### 4. Примеры промптов

**Пример 1. Объяснение кода**

«Ты помощник программиста. Объясни данный код Python простыми словами. Расскажи, что делает каждая важная часть программы. В конце приведи пример использования».

**Пример 2. Анализ ошибок**

«Ты специалист по Python. Найди ошибки в данном коде, объясни причину их появления и предложи исправленный вариант».

**Пример 3. Создание тестов**

«Создай тесты для данной функции Python. Проверь обычные значения, граничные случаи и неправильные входные данные. Используй unittest».

**Пример 4. Создание документации**

«Напиши документацию к данной функции. Укажи её назначение, параметры, возвращаемое значение и пример использования».

**Пример 5. Поиск проблем**

«Проверь данный код Python. Найди ошибки в логике, повторения кода и возможные проблемы безопасности. Предложи способы исправления».

### 5. Полученные результаты

В ходе демонстрации были рассмотрены пять сценариев работы помощника.

- При объяснении кода AI описал назначение функции и её основные элементы.
- При анализе ошибок AI обнаружил неправильное имя переменной и предложил исправление.
- При создании тестов AI подготовил несколько проверок с помощью unittest.
- При создании документации AI описал параметры функции и её результат.
- При проверке кода AI обнаружил возможные проблемы с хранением пароля.

Полученные ответы были проверены вручную на простых примерах. В рассмотренных случаях предложения AI соответствовали логике проверяемого кода.

### 6. Ограничения и недостатки

У AI-помощника есть несколько ограничений:

- AI иногда может давать неправильные ответы.
- Для сложных программ может потребоваться дополнительный контекст.
- Сгенерированный код необходимо проверять и запускать самостоятельно.
- Помощник не подключён к ChatGPT автоматически и не отправляет запросы через API.
- Качество результата зависит от того, насколько правильно составлен промпт.

### 7. Вывод

В результате работы была разработана концепция собственного AI-помощника для программиста CodeHelper AI и создана простая программа на Python с консольным меню.

Я считаю, что искусственный интеллект может быть полезным инструментом в работе программиста. Он помогает быстрее разбираться в коде, находить ошибки, создавать тесты и документацию.

Однако полностью полагаться на AI нельзя. Программист должен самостоятельно проверять полученные ответы и понимать код, который использует.

Таким образом, AI является хорошим дополнительным инструментом, который повышает продуктивность программиста, но не заменяет его знания и навыки.
